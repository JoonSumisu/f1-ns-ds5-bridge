# 接线与供电

## 线缆总表(4 根杜邦)

| TX 板(ESP32) | RX 板(ESP32-S3) | 用途 |
|---|---|---|
| GPIO25 | GPIO5 | UART 数据(TX→RX,921600) |
| GPIO26 | GPIO6(或 GPIO4,两脚同输出) | 振动回传(RX→TX) |
| GND | GND | 共地(**必需**,没有它 UART 全误码) |
| VIN(5V) | 板上真 5V 点(见下) | 供电桥(可选,见供电方案 A) |

⚠️ **"5V 排针"陷阱**:部分双 Type-C 板的排针 5V 脚只连原生口 VBUS(经 OR 二极管),用另一个口供电时量到 ~2.9V 是高内阻万用表的幽灵电压,**不代表有真 5V 输出能力**。搭供电桥前先量:排针 5V 脚无真 5V(≈5V)就焊到板上 **AMS1117 稳压器的输入脚**——任何口供电时那里必有 ~4.7-5V。

## 供电方案(二选一)

**方案 A(推荐,整套只插一根 USB 线)**

```
F1 ═蓝牙NS档═> TX 板
                GPIO25 ──> RX GPIO5      数据
                GPIO26 <── RX GPIO6      振动
                GND ═════ RX GND
                VIN <──── RX 板真 5V 点   供电桥
RX 原生 USB ──> PC   ← 唯一的 USB 线(数据 + 整套供电)
```

插上 USB 两板同时上电,拔下同时断电,不存在插拔顺序问题;TX 板 CP2102 口平时留空。

**方案 B(不焊接)**:TX 板 CP2102 → 手机充电头(隔离电源),只接 3 根杜邦(去供电桥)。

## 安全铁律(一块 S3 的学费,详见 research-notes.md 第 9 节)

**这套装置的所有 USB 线,任何时刻只能连同一台电脑**(或全部用充电头)。

- 两台电脑同时在线(哪怕一台只是经杜邦线共地)= 热插拔瞬间地电位差泄放 → USB 口 VBUS 保护二极管(SS54)击穿,实测烧板
- 想同时用两个口(如供电口+数据口):必须同一台电脑,插拔顺序随意
- 刷机要换电脑:先把另一台侧的所有线拔干净

## 刷机时的接法

刷任一块板之前,**先把两板间的杜邦线全部拔掉**,单板孤立刷写,完了再接回。TX 板刷机(CP2102 接电脑)期间 RX 板若经供电桥连着会被反向点亮,无害,但保持"先拔线"习惯最稳。

## USB 口坏了怎么救

症状:某口插上完全无反应。

1. 换一根确认过的**数据线**、正反两面各试一次(排除线/插向)
2. 换另一个口供电、坏口只插主机——若设备枚举成功 = 只是 VBUS 二极管烧断,数据通道完好,**两口分工**(一口充电头/另一 USB 口供电,坏口跑数据)即可救活
3. 目视+万用表定位鼓包/短路件(通常在坏口旁边,丝印 SS34/SS54 的肖特基),拆掉或换新;拆掉即恢复(代价:两口别再同时插不同电脑)
